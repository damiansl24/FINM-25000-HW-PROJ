# FINM 25000 - Part 1, Algorithmic Trading

This repository contains directories for all homework assignments
and the final project that pertain to this section of the course. 

There is a parent requirements.txt file: this was set up in pre-emptively,
as our assumption is that the packages required for the homework / projects
assigned in this course will rely on the same packages (hence also why
the repository was set up in such a way). 

## To set up your environment:

in terminal type:

cp .env.example .env

then go to the .env file, paste in the alpaca API key and
alpaca secret key. Everything should work after that.
